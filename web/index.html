Ask OLake

A docs assistant for OLake and OLake Fusion. It answers only from the official docs and GitHub repos, cites every source, and says so when it doesn't know.

or click the bubble in the corner.

Embed it in any docs site

One script tag. The widget renders inside a Shadow DOM, so it can't break your site's CSS, and your CSS can't break it.

Options: data-theme="auto|light|dark", data-position="right|left", data-open="true". JS API: AskOLake.open(), AskOLake.ask("question").

Or call the API directly
